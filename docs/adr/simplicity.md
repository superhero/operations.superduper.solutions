# Simplicity

> [!IMPORTANT]
> Simple, clear solutions take precedence over unnecessary complexity.

> [!NOTE]
> Less is more.

> [!NOTE]
> Keep it simple.

## Implementation

- prefer the smallest clear solution;
- avoid unnecessary abstractions and dependencies;
- do not build features before they are needed;
- favor readable, maintainable code over cleverness.

## Presentation

- show only the information needed for the current context, while keeping supporting information available on demand;
- prefer concise labels over permanently visible explanations.
