# Browser-local model families

Selecting or reselecting a language model loads it automatically; opening a menu or page does not download weights. Enter submits the editable prompt; Shift+Enter adds a line. Inference runs in the browser, with the existing application tools and credentials/execution boundaries.

The canonical [language catalog](../src/lib/assistant/language-profiles.json) includes Bonsai2 (2B/4B/9B/27B), Ornith1.5 9B (Q4_K_M/Q8_0), Gemma4 E2B and MiniCPM5~2.52B. It retains exact publisher revisions, files, representations, runtime sources and acceptance attempts. Language profiles are text-only; WebML receives explicit `mmproj:null`. Gemma uses LiteRT-LM0.18.0 GPU_ARTISAN with greedy decoding, context4096 by default, reasoning and prefix caching off. Ornith and MiniCPM retain the native Wllama tool parser. Ornith weights cannot fit the four-GiB CPU heap. MiniCPM's automatic allocation fallback uses eight GPU layers before an eligible CPU retry; network/format errors never trigger placement or precision substitution.

The [LFM2.5-VL1.6B image tool](../src/lib/assistant/vision-profile.json) receives original local image bytes. Only IDs/dimensions enter text prompts. It releases text, uses native512-square white letterboxing with context1024/greedy output256, disposes vision and restores the exact text settings while the Pi Agent/transcript/skills remain alive. It requires verified WebGPU shader-f16. Conversations retain at most three images of up to10MiB/16MP. New conversation clears them. Gemma/MiniCPM image requests default to20 minutes total with three-minute text turns. Cancellation or unknown/failed cleanup can leave text unloaded. Speech capture/finalization and model computation are serialized; speech ORT1.30 and vision's pinned ORT1.31 stay separate.

The [decision catalog](../src/lib/assistant/decision-profiles.json) offers D3 lite0.8B BF16/nano2B Q8/mini4B Q8/flash9B Q8; Strands2B INT4 CPU and WebGPU; KnowLine Gen5.5 4B Q8; Elephant-1 9B Q4_K_M; and Perplexity Flash4B Q8. Expand Assistant configuration, then Decision models. Unload language before selecting a decision model. Score decision sends one explicit state/question and never executes workflows. Results preserve native probabilities/confidence, raw diagnostics and preparation evidence. Confidence definitions differ by family.

Decision lifecycle is `load → prepare → validate → score → dispose`. One question named`q` uses yes/no, ordered choice or ordered score criteria. Exact formatted input is capped at1024 tokens. Guards reject native fitting/truncation and capacity loss before forward. KnowLine reserves a sample position and keeps read-twice/top64 checks; Elephant keeps complete prefix/suffix blocks; Perplexity keeps its interior marker/trailing tokens and protocol-v3 calibration. D3 uses the corrected four-GiB no-forward inspector and native SystemOne handler. D3-lite's template hash comes from accepted run`browser-decisions-1792919408113293110`. Strands keeps its pointer head, complete-versus-fitted input checks and explicit device binding. There is no generated-answer parser or application answer cache.

`build/assistant-runtime.mjs` emits optional workers separately. Native artifacts include receipts and public-source recipe inputs; npm packages are exact-pinned. Large Wasm uses transparent gzip rewrites/headers, retaining decoded hashes. No weights or inference server are bundled. Development serves built assets or installed pinned packages. Same-origin COOP and credentialless COEP establish cross-origin isolation.

Reference acceptance is from the read-only `llm-sds-01` browser-assistant/decision reports. [Source provenance](../src/lib/assistant/reference-sources.json) and decision vendor records retain exact hashes. Operations checks adapter ABI/settings, real Pi swaps with controlled engines, request/result guards, rendered controls, actual worker imports, Wasm compilation and transport hashes without downloading models. These checks preserve reference acceptance and do not constitute new inference/performance measurements for every model/device. Loading establishes memory fit; mobile inference remains unqualified. [Dependency notices](../src/lib/assistant/NOTICES.md) accompany the runtime distribution.
